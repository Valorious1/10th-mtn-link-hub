# 10th Mountain Link Hub (Unofficial)

**Unofficial personal link hub.** This site is **not** endorsed by the U.S. Department of Defense, the U.S. Army, or the 10th Mountain Division. It is not an official public-affairs product. No official seals or government branding.

## What this is

A curated list of **public** links (official Army pages, social accounts, Fort Drum unit pages, alumni association, news hubs), plus a clearly marked **“Not the division”** quarantine for lookalike or unrelated sites.

Link inventory is source-of-truth only — no invented URLs. Live-status badges (e.g. `200`, `soft-403`, `login-wall`) reflect last known check stamps and may change.

## Stack

Static HTML + CSS. No framework. Deployed via Cloudflare Pages (prefer GitHub → Pages).

## Local preview

Open `index.html` or serve the folder:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```
